# components/ui

Auto-generated / hand-rolled **primitive** components in the shadcn/ui
style (Button, Card, Dialog, Input, etc.). Nothing here should know about
Purpose AI's domain (projects, chatbot) — these are the atoms every
other component folder composes.

Populate via `npx shadcn@latest add <component>` once UI work begins;
config already points here (see `components.json`).
